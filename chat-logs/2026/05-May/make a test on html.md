> 💡 **Explanation:** `<!DOCTYPE html>` is not an HTML tag; it is a document type declaration that ensures modern browsers render HTML5 elements accurately in "standards mode" instead of "quirks mode".

# 🧠 Question Bank (Hard / Advanced Level)

### **Q1. Iframe Sandbox Security Vulnerability**
```html
<iframe src="untrusted.html" sandbox="allow-scripts allow-same-origin"></iframe>
```
* **Question:** Why is combining `allow-scripts` and `allow-same-origin` considered a critical security vulnerability?
* **Correct Answer:** It allows the embedded script to access the parent window's DOM and remove its own `sandbox` attribute, completely escaping the sandbox.
* 💡 **Deep Spec Note:** If both permissions are present, the iframe script runs under the same origin as the embedding page, allowing it to execute `window.parent.document.querySelector('iframe').removeAttribute('sandbox')`.

---

### **Q2. `<dialog>` Element: `showModal()` vs `show()`**
```javascript
const dialog = document.querySelector('dialog');
dialog.showModal();
```
* **Question:** What is the critical distinction between `dialog.showModal()` and `dialog.show()`?
* **Correct Answer:** `showModal()` elevates the element into the browser's native **Top-Layer** (above all `z-index` contexts), renders a `::backdrop` pseudo-element, traps keyboard focus, and blocks interactions with the rest of the page.
* 💡 **Deep Spec Note:** `show()` merely renders an inline popup without focus trapping or backdrop blocking.

---

### **Q3. Web Font Preload & CORS**
```html
<link rel="preload" href="/fonts/outfit.woff2" as="font" type="font/woff2" crossorigin>
```
* **Question:** Why **MUST** the `crossorigin` attribute be specified when preloading web fonts, even if the font file is hosted on the same origin?
* **Correct Answer:** The CSS Font-Loading specification strictly mandates fonts to be fetched via CORS; omitting `crossorigin` triggers a double network download due to cache key mismatch.
* 💡 **Deep Spec Note:** Fonts loaded via `@font-face` always use anonymous CORS mode. If `<link rel="preload">` omits `crossorigin`, it fetches in non-CORS mode, causing the browser to reject the preloaded cache entry when parsing CSS.

---

### **Q4. HTML Parser Tree Construction Quirks**
```html
<p>Welcome to <div>NextSem</div> Academy</p>
```
* **Question:** How does the HTML5 parser construct the DOM tree when a `<div>` is placed inside a `<p>` tag?
* **Correct Answer:** The parser implicitly auto-closes the `<p>` before the `<div>`, rendering them as siblings: `<p>Welcome to </p><div>NextSem</div>Academy<p></p>`.
* 💡 **Deep Spec Note:** `<p>` has phrasing content model restrictions. Encountering a block-level start tag like `<div>` triggers the parser's auto-close rule.

---

### **Q5. `<template>` DocumentFragment Behavior**
```html
<template id="card-tpl">
  <script>console.log("NextSem!");</script>
  <img src="avatar.png">
</template>
```
* **Question:** What occurs when the browser parses a `<template>` containing `<script>` and `<img>`?
* **Correct Answer:** The contents remain inert inside a `DocumentFragment`—the script does **not** execute and the image does **not** download until instantiated via JavaScript (`document.importNode` or `cloneNode`).

---

### **Q6. Form Binary Enctype**
```html
<form action="/upload" method="POST" enctype="multipart/form-data">
  <input type="file" name="doc">
</form>
```
* **Question:** Why is `enctype="multipart/form-data"` mandatory for file uploads?
* **Correct Answer:** The default `application/x-www-form-urlencoded` only sends the file's filename string. Only `multipart/form-data` transmits raw binary payload data separated by MIME boundary delimiters.

---

### **Q7. The Global `inert` Boolean Attribute**
```html
<div id="drawer" inert>
  <button>Action</button>
</div>
```
* **Question:** What effect does the native `inert` attribute have on an element and its descendants?
* **Correct Answer:** It disables all pointer/user interactions, removes the subtree from the keyboard tab order, and conceals it from accessibility tree/screen readers.

---

### **Q8. Keyboard Navigation: `tabindex` Values**
```html
<div tabindex="3">Card A</div>
<div tabindex="0">Card B</div>
<div tabindex="-1">Card C</div>
```
* **Question:** Why is positive `tabindex` (e.g., `tabindex="3"`) an accessibility anti-pattern?
* **Correct Answer:** It hijacks natural document order, forcing focus through all positive numbers before reaching natural interactive elements (`<a>`, `<button>`, `tabindex="0"`).

---

### **Q9. Content Security Policy (CSP) `<meta>` Limits**
```html
<meta http-equiv="Content-Security-Policy" content="...">
```
* **Question:** Which CSP directive **CANNOT** be set via a `<meta>` tag and must be transmitted via HTTP headers?
* **Correct Answer:** `frame-ancestors` (along with `report-uri` and `sandbox`), because the browser begins framing before parsing HTML `<meta>` tags.

---

### **Q10. Subresource Integrity (SRI)**
```html
<script src="https://cdn.example.com/lib.js"
  integrity="sha384-oqVuAfXRKap7fdgcCY5uykM6+R9GqQ8K/uxy9rx7HNQlGYl1kPzQho1wx4JwY8n"
  crossorigin="anonymous"></script>
```
* **Question:** What happens if a CDN file is modified and its SHA-384 cryptographic hash differs from the `integrity` attribute?
* **Correct Answer:** The browser immediately refuses to execute the script and logs a network security failure in the console.

---

### **Q11. `<picture>` Fallback Mechanics**
```html
<picture>
  <source media="(min-width: 1024px)" srcset="desktop.webp">
  <img src="mobile.jpg" alt="Hero">
</picture>
```
* **Question:** Why is the nested `<img>` element required inside `<picture>`?
* **Correct Answer:** The `<img>` tag is the actual DOM rendering node; `<picture>` and `<source>` only provide source selection rules to update the `<img>.currentSrc`.

---

### **Q12. ARIA Live Regions**
```html
<div aria-live="assertive">Critical Server Alert</div>
```
* **Question:** What is the functional difference between `aria-live="assertive"` and `aria-live="polite"`?
* **Correct Answer:** `assertive` immediately cuts off ongoing screen reader speech, whereas `polite` waits until the user is idle before announcing.

---

### **Q13. Selective Validation: `formnovalidate`**
```html
<button type="submit" formnovalidate>Save Draft</button>
```
* **Question:** What does `formnovalidate` on a submit button achieve?
* **Correct Answer:** It bypasses native HTML5 client-side constraint validation for that specific submission button only (ideal for saving incomplete drafts).

---

### **Q14. XSS & Attribute Value Escaping**
* **Question:** Why must quotes and ampersands be HTML-escaped when inserting user data into attributes (e.g. `<input value="...">`)?
* **Correct Answer:** To prevent attribute boundary breakout and Reflected XSS injection (e.g., injecting `" autofocus onfocus="alert(1)`).

---

### **Q15. HTML5 Microdata & Schema.org**
```html
<div itemscope itemtype="https://schema.org/Product">
  <span itemprop="name">Course Pass</span>
</div>
```
* **Question:** What do `itemscope`, `itemtype`, and `itemprop` provide?
* **Correct Answer:** They embed structured semantic data into the DOM to generate Google Search Rich Snippets and Knowledge Graph cards.
