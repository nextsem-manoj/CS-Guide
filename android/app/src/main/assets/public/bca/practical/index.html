🗓️ 3-Year / 6-Semester Practical Progression

A seamless curriculum from Day 1 setup to Semester 6 production deployment.

⚡Semester 1: Common Technical Foundation

Year 1 Focus

Developer setup, Windows 11 terminal commands, HTML5, CSS3, basic JavaScript logic, and GitHub workflows.

Core Theory & Lab Subjects:

  • •BCS-111 / BCS-011: Computer Basics
  • •BCSL-013: PC Software Lab
  • •BCS-012: Basic Mathematics

Practical Lab Milestones:

  • ✔Sprint 1 (Days 1–30): HTML5 & CSS3
  • ✔Sprint 2 (Days 31–60): Responsive Layouts & Git
  • ✔🪟 Windows 11 Terminal & GitHub Push

⚡ 3-Year Practical Sprints (12 Sprints • 360 Days)

Two intensive 30-day coding sprints per semester to build real developer muscle memory.

Days 1–30Sem 1 • Foundation

Sprint 1: Web Foundation & Semantic HTML/CSS

Learn modern semantic HTML5, clean CSS layouts, responsive design, and developer command line workflow.

Milestone Project:Interactive Developer Portfolio v1 (Day 30 Mini Project)
Days 31–60Sem 1 • Frontend

Sprint 2: Modern CSS Layouts, Grid & Git Workflows

Master advanced Flexbox, CSS Grid systems, animations, media queries, and professional GitHub repository publishing.

Milestone Project:Responsive University Campus Portal (Day 60 Project)
