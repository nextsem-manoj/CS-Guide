Generate the First N Terms of the Fibonacci Series

Jump to Section: Algorithm • Flowchart • Trace Table • ⚡ Live C++ Compiler
📋

Problem Statement

Given an integer N >= 1, print the first N numbers of the Fibonacci sequence: 0, 1, 1, 2, 3, 5, 8, 13... using a three-variable sliding window.

📊

Variable Dictionary / Table

Variable Name Data Type Role & Purpose
N Integer Total number of terms requested
T1, T2 Long Long First and second terms of window (0 and 1)
nextTerm Long Long Sum of previous two terms (T1 + T2)
count Integer Term counter running from 3 to N
📝

Step-by-Step Formal Algorithm

Step 1: Start.
Step 2: Read positive integer N.
Step 3: If N <= 0:
         Print 'Invalid count' and Stop.
Step 4: If N == 1:
         Print '0' and Stop.
Step 5: Initialize T1 = 0, T2 = 1.
Step 6: Print T1, T2.
Step 7: Initialize count = 3.
Step 8: While (count <= N):
         nextTerm = T1 + T2
         Print nextTerm
         T1 = T2
         T2 = nextTerm
         count = count + 1
Step 9: Stop.

#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter the number of terms N: ";
    if (!(cin >> n) || n <= 0) {
        cout << "Please enter a positive integer (N >= 1).\n";
        return 1;
    }

    long long t1 = 0, t2 = 1;
    cout << "\nFibonacci Series (" << n << " terms):\n";

    if (n == 1) {
        cout << t1 << "\n";
        return 0;
    }

    cout << t1 << ", " << t2;
    for (int count = 3; count <= n; ++count) {
        long long nextTerm = t1 + t2;
        cout << ", " << nextTerm;
        t1 = t2;
        t2 = nextTerm;
    }
    cout << "\n";
    return 0;
}

Developer & Exam Key Takeaway

Iterative sliding window yields O(N) time and O(1) space, vastly outperforming naive recursion which runs in exponential O(2^N) time.
