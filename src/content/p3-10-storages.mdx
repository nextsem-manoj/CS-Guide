# P3.10: Client Local & Session Storage

LocalStorage allows web apps to save key-value strings directly inside the user's browser, persisting data even when the page is closed.

---

## 1. Set and Get Items
* **`localStorage.setItem("key", "value")`**
* **`localStorage.getItem("key")`**

---

## 🎓 Practice Assignment
1. Store a user's theme preference (e.g. `dark`) in localStorage.
2. Write a script that checks this value on load and toggles the body class accordingly.
