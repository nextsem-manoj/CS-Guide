# Chapter 7: Copying, Moving, Renaming, and Deleting Files

## 📄 File Manipulation Operations

Managing system records at the command line requires familiarity with the primary file operations:

* 📑 **`copy [source] [destination]`**: Duplicates a file to a new name or directory path.
* 📦 **`move [source] [destination]`**: Moves a file from its current path to another folder, or renames a directory.
* 🏷️ **`ren [oldname] [newname]`**: Renames a file or folder (short for *rename*).
* 🗑️ **`del [filename]`** (or `erase`): Deletes files.
* 📄 **`type [filename]`**: Displays the text content of a file on-screen.

---

## 🛠️ Advanced Operation Switches

For bulk automation, these commands support powerful parameters to control behavior and prompt prompts:

### Overwriting Confirmation Controls (`/Y`)
By default, if you copy or move a file to a destination where a file with the same name already exists, 🪟 Windows asks if you want to overwrite it.
* **`/Y`**: Suppresses the prompt, automatically overwriting any existing files.
* **`/-Y`**: Explicitly forces the confirmation prompt.

```cmd
copy /Y index.html backup.html
```

### Force Deleting Read-Only Files (`/F` and `/S` in `del`)
By default, the `del` command fails with `"Access is denied"` if a file is marked with the Read-Only (+r) attribute.
* **`/F`**: Forces deletion of read-only files.
* **`/S`**: Deletes specified files from the current folder and all subdirectories.
* **`/Q`**: Runs in quiet mode (does not prompt you before deleting wildcards).

```cmd
del /f /s /q test-logs\*.log
```

---

## 📂 Bulk Folder Duplication with `xcopy`

The standard `copy` command only duplicates *individual files*, not folders. To copy folders, subfolders, and all contained files, use **`xcopy`**:

* **`/S`**: Copies directories and subdirectories, *excluding* empty ones.
* **`/E`**: Copies directories and subdirectories, *including* empty ones.
* **`/Y`**: Suppresses prompts to overwrite files.

```cmd
xcopy Nextsem Backups\Nextsem-Backup /E /Y
```
