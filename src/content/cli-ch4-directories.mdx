# Chapter 4: Working with Directories

## 📂 Managing Directories & Navigation

Managing directories (folders) without a mouse is one of the most fundamental skills in 🪟 Windows 11 system administration.

* **`mkdir [name]`** (or `md`): Creates a new folder. Remember the **Zero-Space Rule** (use hyphens like `Week-1` instead of spaces).
* **`cd [folder]`**: Steps inside a specific folder (relative path navigation).
* **`cd ..`**: Moves backward one step to the parent directory.
* **`cd \`**: Jumps all the way back to the root directory of the active drive.

---

## 🔍 Advanced Directory Audits with `dir`

The `dir` command list files and folders, but you can refine its output using switches:

| Switch | Action | Example |
| :--- | :--- | :--- |
| **`/P`** | Pauses output page-by-page (useful for very large folders). | `dir /p` |
| **`/W`** | Lists directories in a wide multi-column layout. | `dir /w` |
| **`/A`** | Filters files by specific attributes: | |
| | * `/AD`: Lists **directories only** (hides files). | `dir /ad` |
| | * `/AH`: Lists **hidden files only**. | `dir /ah` |
| **`/O`** | Sorts files (e.g. `/ON` sorts by name, `/OS` sorts by size). | `dir /os` |
| **`/S`** | Searches the current directory and all subdirectories for matching files. | `dir *.txt /s` |

---

## 🧹 Deleting Directories with `rmdir` (or `rd`)

To remove a directory, use the `rmdir` command:
```cmd
rmdir Nextsem
```

> [!WARNING]
> **Directory Not Empty:**
> By default, `rmdir` will fail if the folder contains any files or other folders!

To force-delete a folder and all of its contents (subfolders and files) recursively, you must use the `/s` (subdirectories) switch:
```cmd
rmdir Nextsem /s
```
