# Chapter 11: Managing User Accounts

## 👥 Managing System Profiles with `net user`

In 🪟 Windows 11, system administrators use the **`net user`** command to manage local accounts, enforce security policies, and configure access permissions:

* **List Accounts:** Running **`net user`** without arguments lists all user profiles registered on the computer (e.g. Administrator, Guest, Student).
* **View Account Details:**
  ```cmd
  net user Student
  ```
  *Displays detailed info for `Student`, such as password expiry, last login time, and group memberships.*

---

## ➕ Creating & Configuring User Accounts

### 👤 Adding a New User
To register a new local user with a defined password:
```cmd
net user coder nextsem123 /add
```
If you want to enter the password securely (hidden from shoulder-surfers), use an asterisk `*`:
```cmd
net user coder * /add
```
*(The shell will prompt you to type and confirm the password without displaying characters on-screen).*

### 🛠️ Enforcing Security Constraints & Options
You can configure strict login limits using inline switches:

| Option Switch | Action | Example |
| :--- | :--- | :--- |
| **`/active:no`** | Temporarily disables the user account. | `net user coder /active:no` |
| **`/expires:08/31/2026`** | Sets an account expiration date (or `/expires:never`). | `net user coder /expires:08/31/2026` |
| **`/passwordreq:yes`** | Requires the user to have a password. | `net user coder /passwordreq:yes` |
| **`/times:M-F,8am-5pm`** | Restricts login hours (e.g. only Monday-Friday, 8 AM to 5 PM). | `net user coder /times:M-F,8am-5pm` |

### 🗑️ Deleting a User
```cmd
net user coder /delete
```

---

## 👑 Assigning Permissions with `net localgroup`

Creating a user only grants standard user permissions. To elevate a user to a local administrator (giving them UAC elevation privileges), add them to the local **Administrators** group:

* **Add to Administrators Group:**
  ```cmd
  net localgroup Administrators coder /add
  ```
* **List Local Groups:** Running **`net localgroup`** without arguments lists all security groups (e.g. Administrators, Users, Guests).
* **Remove from a Group:**
  ```cmd
  net localgroup Administrators coder /delete
  ```

> [!IMPORTANT]
> **Elevation Required:**
> All user account creation (`net user /add`) and group modification (`net localgroup /add`) commands require **elevated administrator privileges** (UAC elevation). If run in a standard prompt, they fail with `System error 5 has occurred. Access is denied.`

> 👥 **Developer Joke:** Why did the local user account cross the Command Prompt? To get admin permission on the other side! 🚧
