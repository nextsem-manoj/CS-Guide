# P3.6: JS Objects & JSON Data

Objects store key-value properties representing structured entities.

---

## 1. Object Syntax
```javascript
const user = {
  name: "Rohan",
  skills: ["HTML", "JS"],
  greet: function() { console.log("Hello!"); }
};
console.log(user.name); // Rohan
```
