# 💻 CLI.1: CLI Introduction & Desktop Navigation

Welcome to the command center! 🚀 Before we write any HTML or CSS, let's learn how to command our operating system directly using text commands.

---

## 🪟 Windows 11 Desktop Navigation

In 🪟 Windows 11, navigation is typically visual. We use the centered **Start Button ⊞** (or press the ⌨️ `Windows Key` on the keyboard) to find settings, apps, and files. 

However, developers prefer speed. Rather than navigating menus with a mouse, we search for and launch the **Command Prompt (cmd.exe)** to get a direct text-based gateway to the operating system.
