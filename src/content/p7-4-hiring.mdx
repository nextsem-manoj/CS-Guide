# P7.4: Freelance & Remote Funnels

Having technical skills is only half the battle; finding clients or companies willing to hire you is the other. In this final curriculum lesson, we explore how to establish client acquisition funnels and write high-converting pitches for remote roles.

---

## 1. Setting Up Freelance Portals (Upwork/Fiverr)

To successfully secure contracts on Upwork or Fiverr:
* **Specific Title**: Avoid generic titles like "Web Developer". Use specific, high-intent titles like "React & MERN Stack Developer | PWA & API Specialist".
* **Portfolio Showcase**: Upload screenshots of your capstone projects with links to your live websites and GitHub source code.
* **Intro Video**: A short 1-minute video introducing yourself, your technical skills, and demonstrating one of your custom dashboard interfaces significantly increases conversion rates.

---

## 2. Writing Cold Pitch Proposals

Clients receive dozens of generic copy-paste proposals. To stand out, keep your cover letters short, personalized, and value-oriented.

### The 4-Part Pitch Formula:
1. **The Hook**: Acknowledge the client's specific problem mentioned in the job description.
2. **The Authority**: Briefly state your technical stack and link 2 relevant portfolio projects.
3. **The Solution**: Explain how you will solve their problem (e.g. "I can implement the Stripe payment intent API inside your React cart using this flow...").
4. **Call to Action**: A direct prompt to schedule a quick 10-minute call.

### High-Converting Pitch Template:
```text
Hi [Client Name],

I saw you are looking for a developer to connect an Express backend API to MongoDB and handle CORS constraints.

I recently built a full-stack e-commerce project featuring a secure MERN dashboard and completed database indexing, which reduced API response time by 24%.

You can check out the source code and details here:
* GitHub: github.com/my-profile/project-repo
* Live Demo: my-project.web.app

I can get started on your database configurations this week. Are you available for a quick 10-minute chat to discuss the details?

Best,
[Your Name]
```
