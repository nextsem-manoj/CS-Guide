# P0.5: Chrome DevTools & Debugging

Google Chrome is more than just a browser—for web developers, it is the primary debugging environment. **Chrome DevTools** is a suite of web authoring and debugging tools built directly into the browser. 

This guide will take you from a DevTools newbie to an expert, covering layout inspection, advanced console hacks, JavaScript debugging with conditional breakpoints, and keyboard shortcuts.

## 3. Console Power-User Hacks

While `console.log()` is useful, Chrome DevTools supports more powerful output formats:

<div className="space-y-4 my-4">
  <div>
    <span className="inline-block text-xs font-bold bg-slate-800 border border-slate-700 text-slate-300 px-2 py-0.5 rounded mb-2">📊 console.table()</span>
    <p className="text-xs text-slate-350 mb-2">Renders an array of objects into a beautiful, sortable table instead of nested dropdowns:</p>
  </div>
</div>

```javascript
const students = [
  { name: "Aman", role: "Frontend", level: 1 },
  { name: "Rahul", role: "Backend", level: 2 }
];
console.table(students);
```

<div className="space-y-4 my-4">
  <div>
    <span className="inline-block text-xs font-bold bg-slate-800 border border-slate-700 text-slate-300 px-2 py-0.5 rounded mb-2">📁 console.group()</span>
    <p className="text-xs text-slate-350 mb-2">Organizes related logs together under collapsible segments:</p>
  </div>
</div>

```javascript
console.group("User Details");
console.log("Name: Manoj");
console.log("Status: Certified");
console.groupEnd();
```

<div className="space-y-4 my-4">
  <div>
    <span className="inline-block text-xs font-bold bg-slate-800 border border-slate-700 text-slate-300 px-2 py-0.5 rounded mb-2">⏱️ console.time() & console.timeEnd()</span>
    <p className="text-xs text-slate-350 mb-2">Accurately measures execution speed for benchmarking database fetches or loop functions:</p>
  </div>
</div>

```javascript
console.time("DB Fetch");
// Run complex task...
console.timeEnd("DB Fetch"); // Outputs: DB Fetch: 1.45ms
```

<div className="p-4 bg-slate-900 border border-slate-800 rounded-xl my-4 text-xs text-slate-350">
  ⚡ <strong>The $\_ Shortcut:</strong> In the Console command prompt, typing <code>$\_</code> returns the value of the most recently evaluated expression. Type <code>2 + 2</code> (press Enter), then type <code>$\_ * 5</code> to get <code>20</code> instantly!
</div>

## 4. Sources Panel & Debugging

Instead of sprinkling `console.log()` everywhere, use **breakpoints** in the Sources panel to pause your code mid-execution and inspect active variable scopes.

<div className="p-4 bg-slate-900 border border-slate-800 rounded-xl my-4 space-y-2 text-xs text-slate-350">
  <div className="flex gap-2">
    <span className="font-bold text-[#04aa6d]">1.</span>
    <span>Open the <strong>Sources</strong> tab in DevTools.</span>
  </div>
  <div className="flex gap-2">
    <span className="font-bold text-[#04aa6d]">2.</span>
    <span>Select your Javascript file from the file explorer sidebar.</span>
  </div>
  <div className="flex gap-2">
    <span className="font-bold text-[#04aa6d]">3.</span>
    <span>Click on any **line number** to place a breakpoint (represented by a blue bullet). Code execution will freeze here.</span>
  </div>
  <div className="flex gap-2">
    <span className="font-bold text-[#04aa6d]">4.</span>
    <span><strong>Conditional Breakpoints:</strong> Right-click a line number, choose <em>Add conditional breakpoint...</em>, and type a condition (e.g. <code>user.age &gt; 18</code>). Code will only freeze if that statement evaluates to true!</span>
  </div>
</div>

## 🎓 Practice Assignment
1. Declare a `const` variable called `topics` that holds an array of **three objects**. Each object should have a `topic` key (string) and a `status` key (string).
2. Use `console.log()` to print the full `topics` array.
3. Use `console.table(topics)` to display the data in a formatted table in the console.
4. Write a `for` loop that iterates over the `topics` array and logs each `topic` value using `console.log()`.
5. Log an error message using `console.error("DevTools mastered!")` to see how error-level logs look in the Console panel.
