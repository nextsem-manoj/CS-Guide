# Chapter 12: Remote Access

## 🔌 Power Operations & Shutdown Controls

Managing 🪟 Windows 11 system states remotely or locally is handled by the **`shutdown`** command. This utility allows you to configure precise power-off actions:

* **`shutdown /s`**: Shuts down the computer.
* **`shutdown /r`**: Restarts the computer.
* **`shutdown /t [seconds]`**: Sets a delay timer before the action runs (e.g. `/t 120` delays the shutdown by 2 minutes).
* **`shutdown /f`**: Forces running applications to close without warning, preventing files from blocking the shutdown process.
* **`shutdown /a`**: Aborts and cancels any active, pending shutdown or restart timer.

### Controlling a Remote Device:
If you have administrative credentials, you can target another computer on your network using the `/m` switch:
```cmd
shutdown /s /m \\office-pc-02 /t 60 /f
```
*This forces a shutdown of the remote computer `office-pc-02` in 60 seconds.*

## 📶 Remote Shell Execution: WinRM & WinRS

To run interactive terminal tools on remote computers across a local area network, 🪟 Windows uses the built-in **Windows Remote Management (WinRM)** and **Windows Remote Shell (WinRS)** utilities.

```mermaid

    style local fill:#1e293b,stroke:#3b82f6,stroke-width:2px,color:#fff
    style remote fill:#1e293b,stroke:#10b981,stroke-width:2px,color:#fff
```

### 1. Enabling WinRM Services (`winrm`)
Before you can connect to a computer remotely, the target machine must have the WinRM listener active. Open an elevated Command Prompt on the *target computer* and run:
```cmd
winrm quickconfig
```
*This command automatically starts the WinRM service, configures it to launch on system boot, and opens required ports in the Windows Defender Firewall.*

### 2. Running Remote Commands (`winrs`)
Once WinRM is active on the remote computer, you can run commands on it from your *local computer* using `winrs`:
* **Check Remote Network Adapter Info:**
  ```cmd
  winrs -r:office-pc-02 ipconfig
  ```
  *This executes the ipconfig command on `office-pc-02` and streams the text output back to your local command prompt window.*
* **Specifying Credentials:**
  If your current local user account does not have admin permissions on the target computer, supply credentials inline:
  ```cmd
  winrs -r:office-pc-02 -u:Administrator -p:SecretPass123 ver
  ```
