# Chapter 1: Command Line Basics

## 🏛️ Command Line Launching & Syntax

* 🖥️ **Default Boot Interface:** By default, 🪟 Windows boots into a graphical user interface (GUI).
* 🚨 **System Diagnostics:** If 🪟 Windows boots into something other than the default graphical interface (or one of the versions of Safe Mode), you can assume that something has gone wrong with your system.
* 💡 **Terminal Access:** You type lines of text in the terminal which the command interpreter (CMD.EXE) converts into instruction sets.

<CommandLineBasicsSimulation />

Every command in ⊞ Windows follows this standard structure:
```bash
COMMAND [arguments]
```
* **Command:** The action you want to perform (e.g. `ver` to check version, or `cls` to clear screen).
* **Arguments:** Extra specifications that tell the command *where* or *how* to act (e.g. `help dir`).

### Basic Shell Commands:
* **`ver`**: Prints your operating system build name.
* **`help [command]`**: Accesses the built-in instruction manual for any command.
* **`cls`**: Clears the console screen of all past text clutter.

### 🖥️ Making the Command Prompt Window Larger

By default, the ⊞ Windows Command Prompt window is not very large. Even if you click the standard **maximize** button, the window will typically not expand to take up more than about a third of your screen space.

To resize and customize the window layout:
1. 🖱️ **Open Properties:** Right-click on the Command Prompt window's top **title bar**, and select **Properties** from the context menu.
2. 🎚️ **Navigate to Layout:** When the Properties dialog window opens, click on the **Layout Tab**.
3. 📏 **Adjust Window Size:** Under the *Window Size* section, you can manually adjust the **Width** and **Height** values (in character units) to expand the default terminal dimensions. Click **OK** to apply!

> [!TIP]
> **Modern Terminal Alternative:**
> In 🪟 Windows 11, you can also use the new **Windows Terminal** app, which supports standard full-screen maximization, tabs, and zoom scaling (`Ctrl` + `+` / `Ctrl` + `-`) out-of-the-box! 🚀
