# Chapter 3: Understanding the Prompt

## ⚡ Customizing the Command Prompt

The text indicator to the left of your cursor is called the **prompt**. It usually shows your active folder path, but did you know you can customize it using the `prompt` command?

By typing `prompt` followed by a text string, you change your prompt indicator:
```cmd
C:\Users\Student> prompt Student$
Student$
```

To restore the default prompt displaying your current directory path, simply run:
```cmd
Student$ prompt
C:\Users\Student>
```

---

## 🎨 Special Prompt Codes

You can use special dollar-sign `$` codes to display dynamic system information in the prompt:

| Code | Output Content | Example Output |
| :--- | :--- | :--- |
| **`$P`** | Current drive and folder path | `C:\Users\Student` |
| **`$G`** | The greater-than angle bracket `>` | `>` |
| **`$D`** | Current system date | `Mon 07/06/2026` |
| **`$T`** | Current system time | `23:45:12.84` |
| **`$V`** | 🪟 Windows version number | `Microsoft Windows [Version 10.0.22621.1702]` |
| **`$S`** | A space character | |
| **`$$`** | A literal dollar sign `$` | `$` |

### Creating the Default Prompt:
The standard prompt you see is generated by the combination of `$P` (current path) and `$G` (greater-than bracket):
```cmd
prompt $P$G
```

## 🎨 Changing Terminal Colors and Window Title

### 🌈 The `color` Command
You can change the background and text color of your command window using the `color` command followed by a two-character hex code (first character for background, second for text):
```cmd
color 0A
```
* `0` = Black background
* `A` = Light Green text (classic matrix style!)

Common color codes include:
* `0` = Black, `1` = Blue, `2` = Green, `3` = Aqua, `4` = Red, `5` = Purple, `6` = Yellow, `7` = White, `8` = Gray, `9` = Light Blue
* `A` = Light Green, `B` = Light Aqua, `C` = Light Red, `D` = Light Purple, `E` = Light Yellow, `F` = Bright White

### 🏷️ The `title` Command
To change the title bar name of the Command Prompt window, use `title` followed by your custom name:
```cmd
title Nextsem Academy Terminal
```
