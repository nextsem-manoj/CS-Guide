# Chapter 14: Task Management

## 📊 Process Auditing with `tasklist`

If an application freezes, hangs, or consumes too much CPU or RAM, system administrators use Command Line tools instead of the graphical Task Manager in 🪟 Windows 11:

* **List Processes:** Running **`tasklist`** displays a table of all active applications and background services, including their **Image Name**, Process ID (**PID**), Session Name, and **Mem Usage** (in KB).
* **Verbose Details (`/v`):**
  ```cmd
  tasklist /v
  ```
  *Displays additional fields including the user account running each process and the exact window title name (e.g. `Nextsem - Google Chrome`).*
* **Filtering Results (`/fi`):**
  You can filter processes using query operators (like `gt` for greater than):
  ```cmd
  tasklist /fi "memusage gt 100000"
  ```
  *Lists only the processes that consume more than 100 MB of system RAM.*

## 🪓 Terminating Tasks with `taskkill`

When a process becomes unresponsive, the **`taskkill`** utility forces it to close:

### 1. Kill by Process ID (`/pid`)
Every running process is assigned a unique numeric **PID** on boot. To terminate a specific instance:
```cmd
taskkill /pid 4902 /f
```
*(The `/f` switch forces the process to close instantly without prompting the user to save work).*

### 2. Kill by Image Name (`/im`)
If you want to close all instances of an application (like closing all open Notepad windows):
```cmd
taskkill /im notepad.exe /f
```

### 3. Tree Kill (`/t`)
Some applications launch multiple sub-processes (child processes). To close a parent process and all of its child processes recursively, use the `/t` switch:
```cmd
taskkill /im chrome.exe /f /t
```
*This terminates Google Chrome and all of its active tabs and extensions at once.*
