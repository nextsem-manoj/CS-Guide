# Chapter 8: Networking

## 🌐 Network Configuration & Diagnostics

Troubleshooting network connectivity and configuring interfaces in 🪟 Windows 11 is handled by a set of command-line tools:

### 📡 The `ipconfig` Command
Displays active network adapter IP details.
* **`ipconfig /all`**: Lists full configuration info including DHCP leases, DNS servers, and MAC address.
* **`ipconfig /flushdns`**: Purges the local DNS resolver cache (crucial when a website changes IPs and you are stuck seeing the old cached site!).
* **`ipconfig /release`** & **`ipconfig /renew`**: Releases and requests a new IP address from the DHCP server.

### ⚡ The `ping` Command
Sends ICMP Echo Requests to verify a remote server's availability and latency:
* **`ping -t [address]`**: Pings the target host continuously (press `Ctrl` + `C` to stop and view statistics).
* **`ping -n 10 [address]`**: Pings the address exactly 10 times.
* **`ping -a [IP]`**: Attempts to resolve the IP address to a computer hostname.

---

## 🧭 Advanced Route Tracing & Domain Lookups

### 🗺️ The `tracert` Command
Traces the route packets take to reach a destination host, showing every intermediate router (hop) and transition latency:
```cmd
tracert nextsem.online
```
*Useful for finding exactly where a network connection is failing or which router is causing lag.*

### 🔍 The `nslookup` Command
Queries the Domain Name System (DNS) server to find the IP address mapping for a domain or check active nameservers:
```cmd
nslookup nextsem.online
```

---

## 🔍 Network Audits: Ports, MACs, & Netsh

### 🔌 The `netstat` Command
Displays active network connections, routing tables, and port states:
* **`netstat -a`**: Displays all active TCP connections and listening UDP/TCP ports.
* **`netstat -n`**: Shows addresses and port numbers numerically (faster since it skips name lookups).

### 🏷️ The `getmac` Command
Quickly lists the Media Access Control (MAC) physical addresses of all network adapters on your device.

### ⚙️ The `netsh` Command
**Network Shell** is a command-line scripting utility that lets you display or modify the network configuration of a computer (e.g. configuring static IPs, modifying 🪟 Windows Defender Firewall rules).

> 💔 **Developer Joke:** Why did the local computer break up with the remote server? It said: "I've been pinging you for hours, but you're giving me nothing but high latency!" 🌐💥
