Calculate Factorial of an Integer (N!)

Jump to Section: Algorithm • Flowchart • Trace Table • C++ Program
📋

Problem Statement

Given a non-negative integer N, compute its factorial N! = 1 * 2 * 3 * ... * N, with appropriate validation for 0! = 1 and error handling for negative inputs.

📊

Variable Dictionary / Table

Variable Name Data Type Role & Purpose
N Integer Input number (0 <= N <= 20)
fact Unsigned Long Long Product accumulator, initialized to 1
i Integer Loop counter running from 1 to N
📝

Step-by-Step Formal Algorithm

Step 1: Start.
Step 2: Read integer N.
Step 3: If N < 0:
         Print 'Error: Factorial undefined for negative numbers' and Stop.
Step 4: Initialize fact = 1, i = 1.
Step 5: While (i <= N):
         fact = fact * i
         i = i + 1
Step 6: Print N, '! = ', fact.
Step 7: Stop.

Complete C++ Program Implementation

C++ 17 / 20

Production-ready, highly commented C++ implementation with input validation, optimal algorithmic complexity, and structured I/O formatting. 

#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a non-negative integer (0 to 20): ";
    if (!(cin >> n)) {
        cout << "Invalid input! Please enter an integer.\n";
        return 1;
    }

    if (n < 0) {
        cout << "Error: Factorial is undefined for negative integers!\n";
        return 1;
    }

    unsigned long long fact = 1;
    for (int i = 1; i <= n; ++i) {
        fact *= i;
    }

    cout << n << "! = " << fact << "\n";
    return 0;
}

Developer & Exam Key Takeaway

Factorial grows super-exponentially. In standard C++, unsigned long long tops out at 20! (2,432,902,008,176,640,000). Beyond N=20, big integer libraries or arrays are mandatory.
