Sum of Digits & Armstrong (Narcissistic) Number Check

Jump to Section: Algorithm • Flowchart • Trace Table • ⚡ Live C++ Compiler
📋

Problem Statement

Given a positive integer N, compute the sum of its decimal digits and simultaneously check if N is a 3-digit Armstrong number (where the sum of the cubes of its digits equals the number itself, e.g., 153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153).

📊

Variable Dictionary / Table

Variable Name Data Type Role & Purpose
N Integer Input integer
Orig Integer Preserves original number
SumDigits Integer Sum of decimal digits
ArmstrongSum Integer Sum of cubes of decimal digits
Rem Integer Extracted digit (temp % 10)
📝

Step-by-Step Formal Algorithm

Step 1: Start.
Step 2: Read positive integer N.
Step 3: Set Orig = N, SumDigits = 0, ArmstrongSum = 0.
Step 4: While (N > 0):
         Rem = N % 10
         SumDigits = SumDigits + Rem
         ArmstrongSum = ArmstrongSum + (Rem * Rem * Rem)
         N = N / 10
Step 5: Print 'Sum of Digits:', SumDigits.
Step 6: If (ArmstrongSum == Orig):
         Print Orig, 'is an Armstrong Number.'
Step 7: Else:
         Print Orig, 'is NOT an Armstrong Number.'
Step 8: Stop.

#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a positive integer: ";
    if (!(cin >> n) || n < 0) {
        cout << "Invalid input! Please enter a non-negative integer.\n";
        return 1;
    }

    int original = n;
    int sumOfDigits = 0;
    int armstrongSum = 0; // Sum of cubes of digits

    int temp = n;
    while (temp > 0) {
        int digit = temp % 10;
        sumOfDigits += digit;
        armstrongSum += (digit * digit * digit);
        temp /= 10;
    }

    cout << "\n========================================\n";
    cout << "Original Number     : " << original << "\n";
    cout << "Sum of Digits       : " << sumOfDigits << "\n";
    cout << "Sum of Cubed Digits : " << armstrongSum << "\n";
    cout << "----------------------------------------\n";

    if (armstrongSum == original) {
        cout << "Result: " << original << " is a 3-DIGIT ARMSTRONG (Narcissistic) NUMBER!\n";
    } else {
        cout << "Result: " << original << " is NOT an Armstrong number.\n";
    }
    cout << "========================================\n";
    return 0;
}

Developer & Exam Key Takeaway

Famous 3-digit Armstrong numbers are 153, 370, 371, and 407. Preserving the original number in a temporary variable before mutating it inside the loop is a crucial exam programming pattern.
