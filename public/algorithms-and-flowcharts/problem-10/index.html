Menu-Driven Temperature Conversion (Celsius ⇄ Fahrenheit)

Jump to Section: Algorithm • Flowchart • Trace Table • C++ Program
📋

Problem Statement

Formulate an interactive menu-driven console application with options: 1. Convert Celsius to Fahrenheit, 2. Convert Fahrenheit to Celsius, 3. Exit. The loop repeats until the user chooses option 3, with validation for invalid menu entries.

📊

Variable Dictionary / Table

Variable Name Data Type Role & Purpose
Choice Integer User menu option (1, 2, or 3)
C Float / Double Celsius temperature
F Float / Double Fahrenheit temperature
📝

Step-by-Step Formal Algorithm

Step 1: Start.
Step 2: Display Menu:
         1. Celsius to Fahrenheit
         2. Fahrenheit to Celsius
         3. Exit
Step 3: Read Choice.
Step 4: If Choice == 1:
         Read Celsius C.
         F = (C * 9 / 5) + 32.
         Print F.
         Go to Step 2.
Step 5: Else if Choice == 2:
         Read Fahrenheit F.
         C = (F - 32) * 5 / 9.
         Print C.
         Go to Step 2.
Step 6: Else if Choice == 3:
         Print 'Exiting program. Goodbye!'
         Go to Step 8.
Step 7: Else:
         Print 'Invalid Choice! Please enter 1, 2, or 3.'
         Go to Step 2.
Step 8: Stop.

Complete C++ Program Implementation

C++ 17 / 20

Production-ready, highly commented C++ implementation with input validation, optimal algorithmic complexity, and structured I/O formatting. 

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int choice;
    cout << fixed << setprecision(2);

    do {
        cout << "\n========================================\n";
        cout << "   TEMPERATURE CONVERTER SYSTEM MENU    \n";
        cout << "========================================\n";
        cout << "  1. Celsius to Fahrenheit (C -> F)\n";
        cout << "  2. Fahrenheit to Celsius (F -> C)\n";
        cout << "  3. Exit Application\n";
        cout << "----------------------------------------\n";
        cout << "Enter your choice (1 - 3): ";

        if (!(cin >> choice)) {
            cout << "Invalid input! Exiting program...\n";
            break;
        }

        switch (choice) {
            case 1: {
                double c;
                cout << "Enter temperature in Celsius (°C): ";
                cin >> c;
                double f = (c * 9.0 / 5.0) + 32.0;
                cout << ">>> Result: " << c << " °C = " << f << " °F\n";
                break;
            }
            case 2: {
                double f;
                cout << "Enter temperature in Fahrenheit (°F): ";
                cin >> f;
                double c = (f - 32.0) * (5.0 / 9.0);
                cout << ">>> Result: " << f << " °F = " << c << " °C\n";
                break;
            }
            case 3:
                cout << "\nThank you for using Temperature Converter. Goodbye!\n";
                break;
            default:
                cout << "\n[!] Error: Invalid selection! Please enter 1, 2, or 3.\n";
                break;
        }

    } while (choice != 3);

    return 0;
}
