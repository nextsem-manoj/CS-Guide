Check Whether an Integer is Prime or Composite

Jump to Section: Algorithm • Flowchart • Trace Table • C++ Program
📋

Problem Statement

Given a positive integer N, determine whether it is a Prime number, Composite number, or Neither (<= 1) using an optimized trial division loop running up to sqrt(N).

📊

Variable Dictionary / Table

Variable Name Data Type Role & Purpose
N Integer (Long Long) Input integer to test for primality
i Integer (Long Long) Loop divisor candidate (2, 3, 5, 7...)
isPrime Boolean Primality flag
📝

Step-by-Step Formal Algorithm

Step 1: Start.
Step 2: Read integer N.
Step 3: If N <= 1:
         Print 'Neither Prime nor Composite' and Stop.
Step 4: If N == 2 or N == 3:
         Print 'Prime Number' and Stop.
Step 5: If N % 2 == 0:
         Print 'Composite Number' and Stop.
Step 6: Initialize i = 3.
Step 7: While (i * i <= N):
         If (N % i == 0):
             Print 'Composite Number' and Stop.
         i = i + 2.
Step 8: Print 'Prime Number'.
Step 9: Stop.

Complete C++ Program Implementation

C++ 17 / 20

Production-ready, highly commented C++ implementation with input validation, optimal algorithmic complexity, and structured I/O formatting. 

#include <iostream>
using namespace std;

int main() {
    long long n;
    cout << "Enter a positive integer: ";
    if (!(cin >> n)) {
        cout << "Invalid input! Please enter a valid integer.\n";
        return 1;
    }

    if (n <= 1) {
        cout << n << " is NEITHER prime nor composite (by definition).\n";
        return 0;
    }
    if (n == 2 || n == 3) {
        cout << n << " is a PRIME number.\n";
        return 0;
    }
    if (n % 2 == 0) {
        cout << n << " is a COMPOSITE number (divisible by 2).\n";
        return 0;
    }

    bool isPrime = true;
    for (long long i = 3; i * i <= n; i += 2) {
        if (n % i == 0) {
            isPrime = false;
            cout << n << " is a COMPOSITE number (divisible by " << i << ").\n";
            break;
        }
    }

    if (isPrime) {
        cout << n << " is a PRIME number.\n";
    }
    return 0;
}

Developer & Exam Key Takeaway

Testing up to sqrt(N) drops time complexity from O(N) to O(sqrt(N)), enabling instant primality verification even for numbers up to 10^12.
