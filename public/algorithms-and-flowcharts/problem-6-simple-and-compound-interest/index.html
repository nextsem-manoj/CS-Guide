Simple & Compound Interest with Tiered Bonus Rate

Jump to Section: Algorithm • Flowchart • Trace Table • C++ Program
📋

Problem Statement

Given Principal (P), annual interest rate (R), and time in years (T), calculate both Simple Interest (SI) and annually compounded Compound Interest (CI). If tenure T > 5 years, apply an additional 2% loyalty bonus rate.

📊

Variable Dictionary / Table

Variable Name Data Type Role & Purpose
P, R, T Float / Double Principal amount, Base rate %, Time period
effectiveRate Float / Double R + 2% if T > 5, else R
SI, CI Float / Double Calculated interest amounts
📝

Step-by-Step Formal Algorithm

Step 1: Start.
Step 2: Read Principal P, Base Rate R, Time T.
Step 3: If P <= 0 or R <= 0 or T <= 0:
         Print 'Invalid input parameters' and Stop.
Step 4: If T > 5:
         effectiveRate = R + 2
Step 5: Else:
         effectiveRate = R
Step 6: Compute SI = (P * effectiveRate * T) / 100.
Step 7: Compute CI = P * ((1 + effectiveRate / 100) ^ T) - P.
Step 8: Print effectiveRate, SI, CI.
Step 9: Stop.

Complete C++ Program Implementation

C++ 17 / 20

Production-ready, highly commented C++ implementation with input validation, optimal algorithmic complexity, and structured I/O formatting. 

#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;

int main() {
    double P, R, T;
    cout << "Enter Principal (P), Base Rate % (R), Time in years (T): ";
    if (!(cin >> P >> R >> T) || P <= 0 || R <= 0 || T <= 0) {
        cout << "Invalid inputs! P, R, and T must be strictly positive.\n";
        return 1;
    }

    double effectiveRate = (T > 5.0) ? (R + 2.0) : R;

    double SI = (P * effectiveRate * T) / 100.0;
    double CI = P * pow(1.0 + (effectiveRate / 100.0), T) - P;

    cout << fixed << setprecision(2);
    cout << "\n========================================\n";
    cout << "   FINANCIAL INTEREST CALCULATION REPORT\n";
    cout << "========================================\n";
    cout << "Principal (P)        : $" << P << "\n";
    cout << "Base Rate            : " << R << "%\n";
    cout << "Tenure (T)           : " << T << " years\n";
    cout << "Effective Rate       : " << effectiveRate << "%" 
         << (T > 5.0 ? " (+2% Long-Term Loyalty Bonus)" : "") << "\n";
    cout << "----------------------------------------\n";
    cout << "Simple Interest (SI) : $" << SI << " (Total: $" << (P + SI) << ")\n";
    cout << "Compound Interest(CI): $" << CI << " (Total: $" << (P + CI) << ")\n";
    cout << "Compounding Edge     : +$" << (CI - SI) << "\n";
    cout << "========================================\n";
    return 0;
}
