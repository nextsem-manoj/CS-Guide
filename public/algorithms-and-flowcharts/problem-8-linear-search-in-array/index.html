Author: Er. Manoj Kumar • Computer Science Fundamentals

Linear Search in an Array of N Elements with Early Exit

Jump to Section: Algorithm • Flowchart • Trace Table • C++ Program
📋

Problem Statement

Given an array Arr of N integers and a target Key, perform a sequential scan from index 0 to N-1. If Arr[i] == Key, record the index, set Found = 1, and immediately break early to eliminate redundant comparisons.

📊

Variable Dictionary / Table

Variable Name Data Type Role & Purpose
N Integer Total number of elements in the array
Arr[0..N-1] Array of Integers Collection of sequential data
Key Integer Target value being searched
Found Integer (Flag 0 or 1) 0 = not found, 1 = found
i Integer Loop iteration index
📝

Step-by-Step Formal Algorithm

Step 1: Start.
Step 2: Read N.
Step 3: Read array elements Arr[0], Arr[1], ..., Arr[N-1].
Step 4: Read target Key.
Step 5: Set Found = 0, i = 0.
Step 6: While (i < N):
         If (Arr[i] == Key):
             Print 'Key found at position i'.
             Found = 1.
             Break loop (Go to Step 7).
         Else:
             i = i + 1.
Step 7: If (Found == 0):
         Print 'Key not present in array'.
Step 8: Stop.

Complete C++ Program Implementation

C++ 17 / 20

Production-ready, highly commented C++ implementation with input validation, optimal algorithmic complexity, and structured I/O formatting. 

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cout << "Enter number of elements in array N: ";
    if (!(cin >> n) || n <= 0) {
        cout << "Invalid array size N!\n";
        return 1;
    }

    vector<int> arr(n);
    cout << "Enter " << n << " integers:\n";
    for (int i = 0; i < n; ++i) {
        cin >> arr[i];
    }

    int key;
    cout << "Enter target key to search: ";
    cin >> key;

    int foundIndex = -1;
    int comparisons = 0;

    // Linear search with early exit
    for (int i = 0; i < n; ++i) {
        comparisons++;
        if (arr[i] == key) {
            foundIndex = i;
            break; // Early exit break
        }
    }

    cout << "\n========================================\n";
    if (foundIndex != -1) {
        cout << "SUCCESS: Target key [" << key << "] FOUND at index " << foundIndex 
             << " (Position " << (foundIndex + 1) << " in array).\n";
        cout << "Comparisons executed : " << comparisons << " of " << n 
             << " (" << (n - comparisons) << " comparisons saved!)\n";
    } else {
        cout << "FAILURE: Target key [" << key << "] NOT FOUND in the array.\n";
        cout << "Comparisons executed : " << comparisons << " (Full scan completed).\n";
    }
    cout << "========================================\n";
    return 0;
}

Developer & Exam Key Takeaway

Early exit reduces average-case time to O(N/2) comparisons. For large datasets, early exit saves millions of CPU cycles.
