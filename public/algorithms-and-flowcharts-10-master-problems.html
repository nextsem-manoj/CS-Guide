Find the Largest of Three Numbers

↑ Back to Top

Problem Statement

Given three distinct numbers A, B, and C, formulate a step-by-step algorithm and draw a flowchart to determine and print the largest number among them.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
A Numeric First input number
B Numeric Second input number
C Numeric Third input number

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read values of A, B, and C.
Step 3: Compare A and B:
         If A > B:
             Check if A > C: If True, Print 'A is Largest'; Else Print 'C is Largest'.

Problem 2 • Loops

Check Whether an Integer is Prime or Composite

↑ Back to Top

Problem Statement

Given a positive integer N, design an algorithm and flowchart to determine whether N is a Prime number (divisible only by 1 and itself) or a Composite number.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
N Integer The input number to test
i Integer Loop divisor counter starting from 2 up to sqrt(N)
isPrime Boolean Flag 1 if prime, 0 if composite

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read positive integer N.
Step 3: If N <= 1, Print 'Neither Prime nor Composite' and go to Step 8.
Step 4: If N == 2, Print '2 is a Prime Number' and go to Step 8.
Step 5: Initialize divisor counter i = 2.
Step 6: While (i * i <= N):
         If (N % i == 0):
             Print 'N is Composite (Divisible by i)'.
             Go to Step 8 (Early Exit).
         Else:
             Increment i = i + 1.
Step 7: If loop finishes without finding divisor, Print 'N is a Prime Number'.
Step 8: Stop.

T1 Integer First term, initialized to 0

Next Integer Sum of prior two terms (T1 + T2)

Step-by-Step Algorithm

Problem 5 • Math

Reverse an Integer and Check for Palindrome

↑ Back to Top

Problem Statement

Design an algorithm and flowchart that reverses the digits of an integer N and checks whether N is a Palindrome (reads the same backward as forward, like 12321).

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
N Integer Original input number
Orig Integer Copy of original number for comparison
Rev Integer Reversed integer, initialized to 0
Rem Integer Extracted rightmost remainder digit (N % 10)

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read positive integer N.
Step 3: Orig = N, Rev = 0.
Step 4: While (N > 0):
         Rem = N % 10.
         Rev = (Rev * 10) + Rem.
         N = floor(N / 10).
Step 5: Print 'Reversed Number is Rev'.
Step 6: If (Rev == Orig):
         Print 'Orig is a Palindrome Number'.
       Else:
         Print 'Orig is NOT a Palindrome Number'.
Step 7: Stop.

↑ Back to Top

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
P Float Principal investment amount
R Float Base annual interest rate (e.g., 7.5)
T Float Investment duration in years
SI Float Calculated simple interest
CI Float Calculated compound interest

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read Principal P, Rate R, and Time T.

Step 4: Check if T > 5:

Step 5: Compute SI = (P * EffectiveRate * T) / 100.

Step 7: Print EffectiveRate, SI, CI.
Step 8: Stop.

Problem 7 • Math

Find Real & Complex Roots of a Quadratic Equation

↑ Back to Top

Problem Statement

Given coefficients a, b, and c of ax^2 + bx + c = 0, find both roots by evaluating the discriminant D = b^2 - 4ac across all three cases: D > 0, D = 0, and D < 0.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
a, b, c Float Quadratic coefficients (a != 0)
D Float Discriminant value (b^2 - 4ac)
root1, root2 Float/Complex The two roots of the equation

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read coefficients a, b, c.
Step 3: If a == 0, Print 'Not quadratic (Linear equation)' and Stop.
Step 4: Compute Discriminant D = (b * b) - (4 * a * c).
Step 5: If D > 0 (Two distinct real roots):
         root1 = (-b + sqrt(D)) / (2 * a).
         root2 = (-b - sqrt(D)) / (2 * a).
         Print root1, root2.
Step 6: Else if D == 0 (Two equal real roots):
         root1 = -b / (2 * a).
         Print 'Real and Equal Roots:', root1.
Step 7: Else (D < 0, Complex conjugate roots):
         realPart = -b / (2 * a).
         imagPart = sqrt(-D) / (2 * a).
         Print 'Complex Roots: realPart +/- imagPart * i'.
Step 8: Stop.

Problem 9 • Math

Sum of Digits & Armstrong (Narcissistic) Number Check

↑ Back to Top

Problem Statement

Calculate the sum of digits of an integer N, and check if N is an Armstrong number (where the sum of the cubes of its digits equals the number itself, e.g. 153 = 1^3 + 5^3 + 3^3).

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
N Integer Positive integer input
Orig Integer Backup of original number
SumDigits Integer Linear sum of digits, initialized to 0
ArmstrongSum Integer Sum of cubes of digits, initialized to 0
Rem Integer Extracted digit (N % 10)

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read positive integer N.
Step 3: Orig = N, SumDigits = 0, ArmstrongSum = 0.
Step 4: While (N > 0):
         Rem = N % 10.
         SumDigits = SumDigits + Rem.
         ArmstrongSum = ArmstrongSum + (Rem * Rem * Rem).
         N = floor(N / 10).
Step 5: Print 'Sum of Digits = SumDigits'.
Step 6: If (ArmstrongSum == Orig):
         Print 'Orig is an Armstrong Number'.
       Else:
         Print 'Orig is NOT an Armstrong Number'.
Step 7: Stop.

SumDigits = 0
ArmstrongSum = 0] Init --> Cond{N > 0 ?} Cond -- Yes --> Calc[Rem = N % 10
SumDigits += Rem
ArmstrongSum += Rem^3

Menu-Driven Temperature Conversion (Celsius ⇋ Fahrenheit)

↑ Back to Top

Problem Statement

Design an interactive menu-driven program algorithm and flowchart where the user chooses whether to convert from Celsius to Fahrenheit, Fahrenheit to Celsius, or Exit.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
Choice Integer User menu selection (1, 2, or 3)
C Float Temperature in Celsius
F Float Temperature in Fahrenheit

Step-by-Step Algorithm

Step 1: Start.
Step 2: Display Menu:
         1: Celsius to Fahrenheit
         2: Fahrenheit to Celsius
         3: Exit Program.
Step 3: Read user Choice.
Step 4: If Choice == 1:
         Read temperature in Celsius (C).
         Compute F = (C * 9 / 5) + 32.
         Print 'Temperature in Fahrenheit is F'.
         Go to Step 8.
Step 5: Else if Choice == 2:
         Read temperature in Fahrenheit (F).
         Compute C = (F - 32) * 5 / 9.
         Print 'Temperature in Celsius is C'.
         Go to Step 8.
Step 6: Else if Choice == 3:
         Print 'Exiting program. Goodbye!'.
         Go to Step 8.
Step 7: Else:
         Print 'Invalid Choice! Please enter 1, 2, or 3'.
         Go to Step 2 (Loop back to Menu).
Step 8: Stop.
