Find the Largest of Three Numbers

🚀 Dedicated Page ↗ ↑ Top

Problem Statement

Given three distinct numbers A, B, and C, formulate a step-by-step algorithm and draw a flowchart to determine and print the largest number among them.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
A Numeric First input number
B Numeric Second input number
C Numeric Third input number

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read values of A, B, and C.
Step 3: Compare A and B:
         If A > B:
             Check if A > C: If True, Print 'A is Largest'; Else Print 'C is Largest'.
         Else (B >= A):
             Check if B > C: If True, Print 'B is Largest'; Else Print 'C is Largest'.
Step 4: Stop.

Always use nested decision trees rather than multiple independent if-statements to minimize redundant comparisons from 3 comparisons to at most 2 comparisons.

📄 problem_1.cpp
GCC 13.2 • C++20 
#include <iostream>
using namespace std;

int main() {
    double a, b, c;
    cout << "Enter three numbers (A B C): ";
    if (!(cin >> a >> b >> c)) {
        cout << "Invalid input! Please enter valid numeric values.\n";
        return 1;
    }

    double largest;
    // Step-by-step nested branching
    if (a >= b) {
        if (a >= c) {
            largest = a;
        } else {
            largest = c;
        }
    } else {
        if (b >= c) {
            largest = b;
        } else {
            largest = c;
        }
    }

    cout << "\n========================================\n";
    cout << "Input values: A = " << a << ", B = " << b << ", C = " << c << "\n";
    cout << "Result      : Largest Number is " << largest << "\n";
    cout << "========================================\n";
    return 0;
}

Check Whether an Integer is Prime or Composite

🚀 Dedicated Page ↗ ↑ Top

Problem Statement

Given a positive integer N, design an algorithm and flowchart to determine whether N is a Prime number (divisible only by 1 and itself) or a Composite number.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
N Integer The input number to test
i Integer Loop divisor counter starting from 2 up to sqrt(N)
isPrime Boolean Flag 1 if prime, 0 if composite

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read positive integer N.
Step 3: If N <= 1, Print 'Neither Prime nor Composite' and go to Step 8.
Step 4: If N == 2, Print '2 is a Prime Number' and go to Step 8.
Step 5: Initialize divisor counter i = 2.
Step 6: While (i * i <= N):
         If (N % i == 0):
             Print 'N is Composite (Divisible by i)'.
             Go to Step 8 (Early Exit).
         Else:
             Increment i = i + 1.
Step 7: If loop finishes without finding divisor, Print 'N is a Prime Number'.
Step 8: Stop.

📄 problem_2.cpp
GCC 13.2 • C++20 
#include <iostream>
using namespace std;

int main() {
    long long n;
    cout << "Enter a positive integer: ";
    if (!(cin >> n)) {
        cout << "Invalid input! Please enter a valid integer.\n";
        return 1;
    }

    if (n <= 1) {
        cout << n << " is NEITHER prime nor composite (by definition).\n";
        return 0;
    }
    if (n == 2 || n == 3) {
        cout << n << " is a PRIME number.\n";
        return 0;
    }
    if (n % 2 == 0) {
        cout << n << " is a COMPOSITE number (divisible by 2).\n";
        return 0;
    }

    bool isPrime = true;
    for (long long i = 3; i * i <= n; i += 2) {
        if (n % i == 0) {
            isPrime = false;
            cout << n << " is a COMPOSITE number (divisible by " << i << ").\n";
            break;
        }
    }

    if (isPrime) {
        cout << n << " is a PRIME number.\n";
    }
    return 0;
}

Calculate Factorial of an Integer (N!)

🚀 Dedicated Page ↗ ↑ Top

Problem Statement

Formulate an algorithm and flowchart to calculate the factorial of a given non-negative integer N, defined as N! = 1 * 2 * 3 * ... * N, with 0! = 1.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
N Integer Non-negative input number
Fact Integer Accumulator product, initialized to 1
i Integer Loop multiplier counter, initialized to 1

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read integer N.
Step 3: If N < 0, Print 'Factorial undefined for negative numbers' and go to Step 8.
Step 4: Initialize Fact = 1 and loop counter i = 1.
Step 5: While (i <= N):
         Fact = Fact * i.
         i = i + 1.
Step 6: Print 'Factorial of N is Fact'.
Step 7: Stop.

📄 problem_3.cpp
GCC 13.2 • C++20 
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a non-negative integer (0 to 20): ";
    if (!(cin >> n)) {
        cout << "Invalid input! Please enter an integer.\n";
        return 1;
    }

    if (n < 0) {
        cout << "Error: Factorial is undefined for negative integers!\n";
        return 1;
    }

    unsigned long long fact = 1;
    for (int i = 1; i <= n; ++i) {
        fact *= i;
    }

    cout << n << "! = " << fact << "\n";
    return 0;
}

Problem Statement

Design an algorithm and flowchart to generate and print the first N terms of the Fibonacci sequence: 0, 1, 1, 2, 3, 5, 8, 13, 21, ...

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
N Integer Total count of terms to print
T1 Integer First term, initialized to 0
T2 Integer Second term, initialized to 1
Next Integer Sum of prior two terms (T1 + T2)
count Integer Iteration counter from 3 to N

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read the number of terms N.
Step 3: If N <= 0, Print 'N must be positive' and go to Step 10.
Step 4: If N == 1, Print '0' and go to Step 10.
Step 5: Initialize T1 = 0, T2 = 1.
Step 6: Print T1, T2 (first two terms).
Step 7: Initialize loop counter count = 3.
Step 8: While (count <= N):
         Next = T1 + T2.
         Print Next.
         T1 = T2.
         T2 = Next.
         count = count + 1.
Step 9: Stop.

📄 problem_4.cpp
GCC 13.2 • C++20 
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter the number of terms N: ";
    if (!(cin >> n) || n <= 0) {
        cout << "Please enter a positive integer (N >= 1).\n";
        return 1;
    }

    long long t1 = 0, t2 = 1;
    cout << "\nFibonacci Series (" << n << " terms):\n";

    if (n == 1) {
        cout << t1 << "\n";
        return 0;
    }

    cout << t1 << ", " << t2;
    for (int count = 3; count <= n; ++count) {
        long long nextTerm = t1 + t2;
        cout << ", " << nextTerm;
        t1 = t2;
        t2 = nextTerm;
    }
    cout << "\n";
    return 0;
}

Reverse an Integer and Check for Palindrome

🚀 Dedicated Page ↗ ↑ Top

Problem Statement

Design an algorithm and flowchart that reverses the digits of an integer N and checks whether N is a Palindrome (reads the same backward as forward, like 12321).

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
N Integer Original input number
Orig Integer Copy of original number for comparison
Rev Integer Reversed integer, initialized to 0
Rem Integer Extracted rightmost remainder digit (N % 10)

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read positive integer N.
Step 3: Orig = N, Rev = 0.
Step 4: While (N > 0):
         Rem = N % 10.
         Rev = (Rev * 10) + Rem.
         N = floor(N / 10).
Step 5: Print 'Reversed Number is Rev'.
Step 6: If (Rev == Orig):
         Print 'Orig is a Palindrome Number'.
       Else:
         Print 'Orig is NOT a Palindrome Number'.
Step 7: Stop.

📄 problem_5.cpp
GCC 13.2 • C++20 
#include <iostream>
using namespace std;

int main() {
    long long n;
    cout << "Enter an integer: ";
    if (!(cin >> n)) {
        cout << "Invalid input! Please enter an integer.\n";
        return 1;
    }

    long long original = n;
    long long temp = (n < 0) ? -n : n;
    long long reversed = 0;

    while (temp > 0) {
        long long rem = temp % 10;
        reversed = (reversed * 10) + rem;
        temp /= 10;
    }

    cout << "\nOriginal Value : " << original << "\n";
    cout << "Reversed Value : " << reversed << "\n";

    if (n >= 0 && original == reversed) {
        cout << "Result         : " << original << " is a PALINDROME number.\n";
    } else {
        cout << "Result         : " << original << " is NOT a palindrome number.\n";
    }

    return 0;
}

Problem Statement

Calculate Simple Interest (SI) and Compound Interest (CI) for Principal P, Rate R, and Time T years, applying a +2% bonus interest rate if the investment period T > 5 years.

💡 Answer hidden • Solve on your own before checking!

Variable Table

Variable Data Type Purpose / Role
P Float Principal investment amount
R Float Base annual interest rate (e.g., 7.5)
T Float Investment duration in years
SI Float Calculated simple interest
CI Float Calculated compound interest

Step-by-Step Algorithm

Step 1: Start.
Step 2: Read Principal P, Rate R, and Time T.
Step 3: If P <= 0 or R <= 0 or T <= 0, Print 'Inputs must be positive' and Stop.
Step 4: Check if T > 5:
         If True: EffectiveRate = R + 2.0 (Bonus Tier).
         Else: EffectiveRate = R.
Step 5: Compute SI = (P * EffectiveRate * T) / 100.
Step 6: Compute CI = P * ((1 + EffectiveRate / 100) ^ T) - P.
Step 7: Print EffectiveRate, SI, CI.
Step 8: Stop.

    double D = (b * b) - (4.0 * a * c);
    cout << fixed << setprecision(4);
    cout << "\n========================================\n";
    cout << "Equation      : (" << a << ")x^2 + (" << b << ")x + (" << c << ") = 0\n";
    cout << "Discriminant D: " << D << "\n";
    cout << "----------------------------------------\n";

    if (D > 0) {
        double sqrtD = sqrt(D);
        double root1 = (-b + sqrtD) / (2.0 * a);
        double root2 = (-b - sqrtD) / (2.0 * a);
        cout << "Nature: REAL, UNEQUAL, AND DISTINCT ROOTS\n";
        cout << "Root 1 = " << root1 << "\n";
        cout << "Root 2 = " << root2 << "\n";
    } else if (D == 0) {
        double root = -b / (2.0 * a);
        cout << "Nature: REAL AND EQUAL ROOTS\n";
        cout << "Root 1 = Root 2 = " << root << "\n";
    } else {
        double realPart = -b / (2.0 * a);
        double imagPart = sqrt(-D) / (2.0 * a);
        cout << "Nature: COMPLEX CONJUGATE ROOTS\n";
        cout << "Root 1 = " << realPart << " + " << imagPart << "i\n";
        cout << "Root 2 = " << realPart << " - " << imagPart << "i\n";
    }
    cout << "========================================\n";
    return 0;
}

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cout << "Enter number of elements in array N: ";
    if (!(cin >> n) || n <= 0) {
        cout << "Invalid array size N!\n";
        return 1;
    }

    vector<int> arr(n);
    cout << "Enter " << n << " integers:\n";
    for (int i = 0; i < n; ++i) {
        cin >> arr[i];
    }

    int key;
    cout << "Enter target key to search: ";
    cin >> key;

    int foundIndex = -1;
    int comparisons = 0;

    // Linear search with early exit
    for (int i = 0; i < n; ++i) {
        comparisons++;
        if (arr[i] == key) {
            foundIndex = i;
            break; // Early exit break
        }
    }

    cout << "\n========================================\n";
    if (foundIndex != -1) {
        cout << "SUCCESS: Target key [" << key << "] FOUND at index " << foundIndex 
             << " (Position " << (foundIndex + 1) << " in array).\n";
        cout << "Comparisons executed : " << comparisons << " of " << n 
             << " (" << (n - comparisons) << " comparisons saved!)\n";
    } else {
        cout << "FAILURE: Target key [" << key << "] NOT FOUND in the array.\n";
        cout << "Comparisons executed : " << comparisons << " (Full scan completed).\n";
    }
    cout << "========================================\n";
    return 0;
}

Calculate the sum of digits of an integer N, and check if N is an Armstrong number (where the sum of the cubes of its digits equals the number itself, e.g. 153 = 1^3 + 5^3 + 3^3).

#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter a positive integer: ";
    if (!(cin >> n) || n < 0) {
        cout << "Invalid input! Please enter a non-negative integer.\n";
        return 1;
    }

    int original = n;
    int sumOfDigits = 0;
    int armstrongSum = 0; // Sum of cubes of digits

    int temp = n;
    while (temp > 0) {
        int digit = temp % 10;
        sumOfDigits += digit;
        armstrongSum += (digit * digit * digit);
        temp /= 10;
    }

    cout << "\n========================================\n";
    cout << "Original Number     : " << original << "\n";
    cout << "Sum of Digits       : " << sumOfDigits << "\n";
    cout << "Sum of Cubed Digits : " << armstrongSum << "\n";
    cout << "----------------------------------------\n";

    if (armstrongSum == original) {
        cout << "Result: " << original << " is a 3-DIGIT ARMSTRONG (Narcissistic) NUMBER!\n";
    } else {
        cout << "Result: " << original << " is NOT an Armstrong number.\n";
    }
    cout << "========================================\n";
    return 0;
}

#include <iostream>

int main() {
    int choice;
    cout << fixed << setprecision(2);

    do {
        cout << "\n========================================\n";
        cout << "   TEMPERATURE CONVERTER SYSTEM MENU    \n";
        cout << "========================================\n";

            break;
        }

        switch (choice) {
            case 1: {
                double c;
                cout << "Enter temperature in Celsius (°C): ";
                cin >> c;
                double f = (c * 9.0 / 5.0) + 32.0;

                break;
